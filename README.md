# ai-agent
AttendAI — Student Attendance Tracker
Technologies Used: 
Frontend: React 18 + Tailwind CSS + Vite
Backend: Base44 BaaS (database, auth, AI integrations),
Target Users: University students tracking personal attendance. 
AttendAI gives real-time visibility, AI-powered suggestions, and a conversational assistant to help students stay on top of attendance.
